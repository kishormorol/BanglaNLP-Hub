# Homepage artwork

`src/assets/art/bangla-river-collage.png` is an original image generated with the
built-in ChatGPT image generation tool on November 4, 2026. Its complete prompt
is preserved in [bangla-river-prompt.txt](bangla-river-prompt.txt). It depicts an
illustrative Bangladesh river landscape made from torn paper, rather than a
photograph of a named place. No Craft artwork was copied or supplied as an input.

The image is decorative. All headings, controls, catalog content, and counts
remain live HTML from the existing application. Astro emits responsive WebP
derivatives at build time. The source PNG stays here for reproducibility.

`src/assets/art/bangla-river-night.png` is the matching night edit, generated
with the built-in ChatGPT image tool using the day PNG as its image reference.
It preserves the landscape composition while replacing the red sun with a bright
moon in the upper-left sky, small stars, and moonlit blue lighting. Its exact
prompt is in [bangla-river-night-prompt.txt](bangla-river-night-prompt.txt) and
embedded in the PNG. Both source images are 1774 × 887 pixels.

The theme toggle changes a native picture source, including saved-theme startup.
The entire image uses `object-fit: contain`. On narrow screens, the panorama sits
between the hero text and catalog preview so the moon and river remain visible.
